## Fixes

- **Android: no longer stuck on "Waiting for Android"** after building the game. If you left the setup app while Android was asking to install the game, its confirmation could stay hidden behind the app, so the setup waited forever. The confirmation now comes back when you return to the app. If nothing answers for 30 seconds, the page explains what to do (Play Protect, Samsung's Auto Blocker).
- **Android: skip the install or do it yourself.** *Skip for now* leaves the install for later: the game stays built and *Install the game* on the start page installs it any time. *Save the APK to Downloads* puts the game's app in your Downloads folder, so you can install it from your file manager.

If you are stuck on "Waiting for Android" with an older version: update this app (*Check for updates*), then use *Install the game* or *Save the APK to Downloads* on its start page. The game does not need to be built again.
